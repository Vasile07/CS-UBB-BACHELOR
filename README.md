# Computer Science Bachelor's Portfolio

A curated collection of coursework, laboratories, and projects completed during my Computer Science bachelor's degree. The repository documents my progression from programming fundamentals and core computer science concepts to application development, data-driven work, and advanced software topics.

## Learning areas

- **Programming:** C, C++, Java, C#, Python, JavaScript, TypeScript, SQL, MATLAB
- **Computer science foundations:** data structures and algorithms, graph algorithms, object-oriented design, formal languages, compiler construction, numerical methods
- **Software development:** layered architecture, validation, persistence, testing, desktop and web interfaces, mobile development
- **Data and intelligent systems:** relational databases, data analysis, machine learning, neural networks, computer vision, generative AI
- **Advanced topics:** parallel and distributed programming, human-computer interaction

The languages and topics listed reflect files and projects currently present in this repository; individual projects may use only a subset.
