# Semester 3 — Application Design and Data

Semester 3 develops application design skills in **Java** alongside relational database concepts and **SQL**.

## Courses and work

### Advanced Programming Methods

The social-network project models users, friendships, and messages using domain entities, validation, repositories, services, and a user interface. The project includes persistence-related and domain tests, demonstrating attention to application structure and behavior.

### Databases

SQL coursework includes schema creation and updates, data insertion, CRUD operations, test scripts, and query exercises. A music streaming service database provides a larger applied example, alongside smaller exercises in domains such as libraries, films, retail, and administration.

## Skills practiced

- Java application architecture and object-oriented design
- Domain modeling, validation, repositories, and services
- Unit testing and exception handling
- Relational schema design and database versioning
- SQL data manipulation and querying
