# Semester 2 — Programming Foundations

This semester focuses on core programming skills and the foundations needed to build reliable, structured software. The coursework is primarily implemented in **C and C++**.

## Courses and work

### Data Structures and Algorithms

Implementations and exercises covering collection behavior, iterators, and common data-structure operations, supported by short and extended tests.

### Graph Algorithms

A dedicated area for graph algorithm coursework and related materials.

### Object-Oriented Programming

A progression of labs and practice projects exploring classes, encapsulation, layered application structure, validation, persistence, testing, and user interfaces. Example domains include films, products, music, cars, and students. Some projects include console and Qt-based interfaces.

## Skills practiced

- C and C++ programming
- Data structures, algorithms, and graph problem solving
- Object-oriented modeling and separation of responsibilities
- Repository, service, domain, and presentation layers
- Input validation, error handling, and automated tests
- Working with files and GUI frameworks
