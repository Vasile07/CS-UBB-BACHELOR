# Semester 5 — Advanced Application Development

Semester 5 brings together several applied areas: compiler construction, user-centered design, intelligent systems, mobile development, and concurrent/distributed programming. The repository includes coursework in **Java, C, JavaScript, TypeScript, Python, HTML, and CSS**.

## Courses and work

### Formal Languages and Compiler Design

Labs and projects cover finite automata, token/identifier processing, and parser or compiler exercises, including materials using Lex/Flex and Bison/Yacc-style tools.

### Human-Computer Interaction

[LexiLearn](Human-computer%20interaction/lexi-learn/) is a web-based reading game designed to support children with dyslexia. Its project README includes additional context and setup guidance.

### Intelligent Methods for Solving Real-World Problems

The [mental health detection server](Intelligent%20methods%20for%20solving%20real-world%20problems/mental-health-detection-server/) contains a Python model-serving project and associated model and label files.

### Mobile Application Programming

The [Zoo application](Mobile%20application%20programming/mobile-zoo-app/) pairs a mobile client with a server project. The client integrates device capabilities such as camera, filesystem, geolocation, maps, and network status; the server uses Node.js libraries for HTTP APIs, database access, authentication, and WebSockets. Practice projects are also included.

### Parallel and Distributed Programming

Java exercises and projects explore concurrent processing patterns, worker/consumer roles, queues, synchronization, and client-server style applications across domains such as banking, pharmacies, schools, transport, and competitions.

## Skills practiced

- Automata, lexical analysis, and parser construction
- User-centered interactive application design
- Python model integration
- Mobile application development and device APIs
- Java concurrency and distributed application patterns
- Web technologies and service/database integration
