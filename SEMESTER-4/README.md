# Semester 4 — Intelligent Systems and Software Design

This semester combines **Python-based AI and data analysis**, **C# application development**, and database management coursework.

## Courses and work

### Artificial Intelligence

Labs and notebooks explore data analysis, regression, gradient descent, optical character recognition (OCR), object detection, artificial neural networks (ANNs), convolutional neural networks (CNNs), and generative AI. The folder includes notebooks and supporting datasets or media.

### Database Management Systems

Course materials and exercises focused on database management concepts.

### Systems for Design and Implementation

A C# desktop application for a swimming competition, organized as a Visual Studio solution and project.

## Skills practiced

- Python notebooks and exploratory data analysis
- Regression, optimization, neural networks, and computer vision concepts
- C# application development and solution-based project organization
- Database management fundamentals
