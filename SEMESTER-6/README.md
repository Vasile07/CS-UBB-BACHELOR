# Semester 6 — Numerical Computing

This semester's repository area contains numerical calculus coursework, primarily as **MATLAB Live Scripts** and supporting **Maple** worksheets.

## Coursework

The folder includes lab and problem-solving materials, supplementary worksheets, and scripts for numerical approximation. Topics are represented through the coursework files rather than a single packaged application.

## Skills practiced

- Numerical computation and approximation
- MATLAB scripting and Live Scripts
- Mathematical problem solving with computational tools
- Organizing reproducible lab work and supporting worksheets
